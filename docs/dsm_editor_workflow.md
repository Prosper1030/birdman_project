# DSM 編輯器使用流程

本文件說明 Birdman 專案目前的 PyQt DSM 編輯器使用方式，包含載入、編輯、循環提示、自動存檔、匯出與恢復流程。

## 1. 啟動方式

### 1.1 獨立啟動

```bash
python3 run_dsm_editor.py --wbs sample_data/WBS.csv --dsm sample_data/DSM.csv
```

可用參數如下：

- `--wbs <path>`：載入 WBS 檔案
- `--dsm <path>`：載入既有 DSM 檔案
- `--direction {TB,LR}`：設定預設佈局方向
- `--debug`：啟動後自動套用一次階層式佈局，方便檢查畫面

若只提供 `--wbs`，編輯器會以空白依賴圖啟動。

### 1.2 從主 GUI 開啟

1. 先在主 GUI 載入 WBS。
2. 若有既有 DSM，也先一併匯入。
3. 點選「DSM 編輯器」功能。

主 GUI 會把目前已載入的 WBS 與 DSM 一起帶入編輯器；若只有 WBS，則開啟空白依賴圖。

## 2. 載入規則

編輯器啟動時會先驗證資料，以下情況會直接阻止載入：

- WBS 為空
- WBS 缺少 `Task ID`
- WBS 存在重複或空白 `Task ID`
- DSM 不是方陣
- DSM 列欄 Task ID 不一致
- DSM 與 WBS 任務不對齊
- DSM 內容不是 `0` 或 `1`

## 3. 編輯流程

### 3.1 畫面重點

- 上方狀態列會顯示來源檔名、是否有未匯出變更、是否存在循環依賴、循環 SCC 數量。
- 右側 `循環 SCC 清單` 會列出所有成環群組。
- 中央畫布可拖曳節點、建立依賴、刪除依賴、切換佈局。

### 3.2 依賴編輯

- 建立依賴時，系統不會阻擋循環。
- 每次新增、刪除、撤銷、重做後，都會立即重算 DSM、循環狀態與 SCC 摘要。
- 點選右側 SCC 清單後，對應節點與邊線會高亮。

### 3.3 循環提示

- 若目前存在循環，狀態列會明確顯示 `循環依賴：有`。
- 匯出與關閉視窗不會因循環被阻擋。
- 但在匯出或關閉時，系統會提示：
  `目前含循環，後續 CPM 或排序分析可能受影響。`

### 3.4 佈局功能

- 可使用階層式、正交式、力導向佈局。
- 若目前含循環，佈局完成後會顯示「視覺化重排完成」，只代表畫面已重新排列，不代表循環已被解除。

## 4. 儲存與備份

### 4.1 匯出 DSM

選單 `檔案 > 匯出 DSM` 會把目前依賴圖輸出為新的 CSV 檔案。

注意：

- 第一版不直接覆寫原始 DSM。
- 匯出是明確產出檔，適合交付後續分析流程。

### 4.2 儲存工作階段

選單 `檔案 > 儲存工作階段` 會把目前 session 快照寫入：

```text
.birdman_autosave/<session-id>/<timestamp>/
```

每份快照包含：

- `dsm_snapshot.csv`
- `wbs_snapshot.csv`
- `session.json`

### 4.3 自動存檔

- 當 DSM 內容與原始來源不同時，編輯器會在 30 秒後自動寫入快照。
- 關閉視窗前，如果仍有未匯出變更，也會再補寫一次快照。
- 每個工作階段只保留最近 10 份快照，超過就刪掉最舊版本。

## 5. 恢復流程

當你再次開啟同一組來源檔時，如果系統發現有比來源檔更新的快照，就會詢問是否恢復最近一次自動存檔。

恢復時的行為如下：

- 會載入快照內的 WBS 與 DSM
- 不會覆寫原始檔案
- 恢復後仍會被視為「尚未匯出回正式輸出檔」

## 6. 目前限制

- v1 只專注 DSM 依賴編輯，不提供完整 WBS 表格編輯介面
- 主 GUI 與 DSM 編輯器目前沒有雙向即時同步
- 工作階段快照以安全保存為主，不會直接回寫原始來源檔
